Singly Linked List Operations in C

About the Project

This project implements basic singly linked list operations using the C programming language.

Operations

1. Insertion at Beginning
2. Insertion at End
3. Deletion from Beginning
4. Display Linked List
5. Search an Element

Technologies Used

- Programming Language: C
- Data Structure: Singly Linked List

Purpose

This project is developed to understand linked list concepts and their practical implementation in Data Structures and Algorithms.
